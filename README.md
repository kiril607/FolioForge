# FolioForge — Portfolio Studio

Конструктор сайтів-портфоліо для розробників і фрилансерів. Двопанельний редактор із живим превʼю, Free/Pro планами, ручним підтвердженням оплати та одноразовими ліцензійними ключами.

## Що вміє

- **Редактор + live preview** — форма зліва, готовий сайт справа, оновлення з debounce.
- **5 розділів** — особисті дані, навички, проєкти, соцмережі, візуальний стиль.
- **Динамічні блоки** — навички, проєкти та соцмережі додаються/видаляються з undo-тостом.
- **Free-план** — 1 базова тема Minimal, 1 шрифт Inter, колір теми без змін, watermark на експорті, до 4 навичок / 2 проєктів / 3 соцмереж.
- **Pro-план** — усі 6 тем, 5 шрифтів, власний акцент, без watermark, до 30 навичок / 12 проєктів / 10 соцмереж.
- **Автозбереження** у `localStorage`.
- **Адаптивне превʼю** — desktop / tablet / mobile.
- **Експорт ZIP** — автономний `index.html` з вбудованими CSS/JS + `README.txt`.
- **Копіювання коду** — копіює повний standalone HTML.
- **Ручна оплата** — покупець залишає заявку, власник підтверджує оплату в `/admin`, покупцю на email надходить одноразовий ключ.
- **Одноразові ключі** — після активації ключ повторно не спрацює; браузер зберігає підписаний lifetime-токен.

> Якщо Pro-доступ втрачено (ліцензію відкликано або токен недійсний), конструктор автоматично повертає Free-тему, шрифт і колір, а також обрізає контент до Free-лімітів: 4 навички, 2 проєкти, 3 соцмережі.

## Структура

```text
index.html        розмітка конструктора, форма, превʼю, paywall
styles.css        дизайн-система конструктора та адаптивність
app.js            стан, рендеринг, генератор сайту, ZIP, Free/Pro, ліцензії
admin.html        адмінка: заявки, підтвердження оплати, ключі
server.js         Node-сервер: статика, API, email, одноразові ключі
package.json      скрипти запуску
.env.example      приклад конфігурації
data/             база заявок/ліцензій і локальний outbox (створюється автоматично)
```

Зовнішніх npm-залежностей немає — потрібен лише Node.js 18+. Єдине зовнішнє підключення сайту — Google Fonts.

## Локальний запуск

```bash
node server.js
```

Відкрийте:

- конструктор — `http://localhost:4173`
- адмінка — `http://localhost:4173/admin`

Під час першого запуску сервер створює:

- `data/admin-token.txt` — токен для входу в адмінку (якщо не заданий `ADMIN_TOKEN`);
- `data/license-secret.txt` — секрет для підпису токенів і шифрування ключів;
- `data/db.json` — заявки та ліцензії;
- `data/outbox/` — листи в демо-режимі, якщо email ще не підключено.

Токен також друкується в консолі під час старту.

## Як працює продаж Pro

1. Покупець натискає **«Оформити FolioForge Pro»** і заповнює заявку: імʼя, email, спосіб оплати, номер транзакції.
2. Заявка зʼявляється в `/admin`, а власнику на `ADMIN_EMAIL` надходить лист-сповіщення.
3. Власник перевіряє, що гроші надійшли, і натискає **«Підтвердити оплату»**.
4. Сервер генерує унікальний ключ `FOLIO-XXXX-XXXX-XXXX`, зберігає його хеш і надсилає покупцю лист із ключем.
5. Покупець вводить ключ у paywall. Сервер перевіряє його, позначає як використаний і повертає підписаний lifetime-токен.
6. Повторно той самий ключ активувати неможливо — сервер відповість `KEY_USED`.

> Якщо покупець втратив доступ до браузера, адміністратор може відкрити ключ в адмінці та надіслати лист повторно. Для повторної активації на новому пристрої потрібен новий ключ або окремий процес відновлення доступу.

## Email

За замовчуванням працює **демо-режим**: листи не надсилаються, а зберігаються в `data/outbox/*.txt`. Це дозволяє пройти весь цикл локально.

Для реальної доставки:

1. Зареєструйтеся на [Resend](https://resend.com).
2. Підтвердіть домен або використайте тестовий `onboarding@resend.dev`.
3. Створіть `.env` на основі `.env.example`:

```env
ADMIN_EMAIL=you@example.com
RESEND_API_KEY=re_xxxxxxxxx
EMAIL_FROM=FolioForge <hello@yourdomain.com>
APP_URL=https://your-domain.com
ADMIN_TOKEN=довгий-випадковий-токен
LICENSE_SECRET=довгий-випадковий-секрет
```

Без `RESEND_API_KEY` усе одно можна підтверджувати оплату та видавати ключі — просто листи лежатимуть у `data/outbox`.

## Деплой

Для повноцінної роботи з оплатою та ключами потрібен **постійний Node-процес** і диск для `data/`.

### Render / Railway / VPS

1. Завантажте проєкт у репозиторій.
2. Start command: `node server.js`.
3. Додайте env-змінні з `.env.example`.
4. Підключіть persistent disk для папки `data/` (інакше заявки й ключі зникнуть після рестарту).
5. Відкрийте `/admin` і підтвердіть тестову заявку.

### Vercel / Netlify

Статична частина задеплоїться, але API з `server.js` там не працюватиме «як є». Для Vercel потрібно перенести маршрути `/api/*` у serverless-функції та підключити зовнішню базу (Vercel KV / Postgres). Для Netlify — Functions + Blobs. Якщо не хочете цього робити, використовуйте Render/Railway/VPS.

### GitHub Pages

Підходить лише для демонстрації інтерфейсу без активації Pro, бо немає серверної частини.

## Налаштування продукту

`app.js`:

```js
const CONFIG = {
  purchaseEndpoint: "/api/purchase",
  licenseEndpoint: "/api/license",
  price: 5,
  currency: "USD",
  productName: "FolioForge Pro",
  brandUrl: "https://folioforge.app",
  paymentInstructions: "", // необовʼязкові реквізити над формою заявки
};

const FREE_PLAN = { themeId: "minimal", fontId: "inter", skills: 4, projects: 2, socials: 3 };
const PRO_PLAN = { skills: 30, projects: 12, socials: 10 };
```

`server.js` / `.env`:

- `PRO_PRICE` — ціна (за замовчуванням 5).
- `ADMIN_EMAIL` — куди надсилати заявки.
- `ADMIN_TOKEN` — токен входу в `/admin`.
- `LICENSE_SECRET` — підпис токенів і шифрування ключів.
- `RESEND_API_KEY`, `EMAIL_FROM` — реальна доставка листів.

### Додати реквізити оплати

Заповніть `CONFIG.paymentInstructions` у `app.js`, наприклад:

```js
paymentInstructions: "Stripe: https://buy.stripe.com/...\nАбо IBAN: UA00 0000 0000 0000 0000 0000 000",
```

Текст зʼявиться над формою заявки.

## Що генерується в ZIP

- `index.html` — повний standalone-сайт: розмітка, CSS, JS, SVG-іконки, favicon, meta/OG-теги.
- `README.txt` — коротка інструкція з деплою та кастомізації.

Експортований сайт:

- адаптивний (mobile/tablet/desktop);
- має доступну навігацію, skip-link, `prefers-reduced-motion`;
- використовує обрану тему, шрифтову пару й акцент;
- підключає Google Fonts;
- на Free-плані містить фіксований watermark «Зроблено у FolioForge · Free», на Pro — ні.

## Кастомізація

- Кольори сайту — CSS-змінні `--accent`, `--accent-rgb`, `--accent-ink`.
- Шрифти — `--font-display`, `--font-body`.
- Теми — обʼєкт `THEMES` у `app.js` (`pro: true` робить тему Pro-only).
- Шрифти — обʼєкт `FONTS` у `app.js` (`pro: true` робить шрифт Pro-only).
- Соцмережі та іконки — `SOCIALS` і `SOCIAL_ICONS`.
- Демо-контент — `DEFAULT_STATE`.

## Безпека

- Ключі зберігаються у вигляді SHA-256 хешу; для повторного надсилання — у зашифрованому вигляді (AES-256-GCM).
- Ліцензійні токени підписуються HMAC-SHA256.
- Адмінка захищена токеном, усі admin-запити перевіряються на сервері.
- Є простий rate limit на заявки та активації.
- Не комітьте `.env` і папку `data/`.

## Доступність

- Форми мають `<label>` та `aria-label`.
- Таби підтримують `ArrowLeft`, `ArrowRight`, `Home`, `End`.
- Paywall закривається `Escape`, утримує фокус і повертає його на тригер.
- Є `aria-live` для тостів і статусу збереження.
- Підтримується `prefers-reduced-motion`.

## Браузери

Сучасні Chrome, Edge, Firefox, Safari. Потрібні `localStorage`, `Blob`, `TextEncoder`, `URL.createObjectURL`, `Intl`/`toLocaleDateString`. Clipboard API має fallback на `execCommand`.

## Ліцензія

Код конструктора можна використовувати як основу для власного продукту. Перед публікацією замініть брендинг, ціну, реквізити та налаштуйте власний email-домен.
